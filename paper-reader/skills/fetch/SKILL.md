# Fetch Sub-Skill

Handles paper retrieval from various sources (arXiv, DOI, URLs, local files).

## Commands

- `fetch <source>` — Fetch a paper from the given source
- `fetch arxiv <id>` — Fetch from arXiv
- `fetch doi <doi>` — Fetch by DOI
- `fetch url <url>` — Fetch from URL
- `fetch file <path>` — Process a local file
